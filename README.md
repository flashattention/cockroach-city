# 🪳 바퀴시티 (Roach City)

인간 도시와 똑같이 돌아가는 **바퀴벌레들의 3D 도시**에서 동료들과 함께 살아가는 멀티플레이 라이프 시뮬레이션 웹 게임입니다.
GTA처럼 3인칭으로 걷고, 뛰고, 차를 빼앗아 운전하고, 건물에 들어가고, LLM으로 대화하는 이웃 바퀴들과 친해질 수 있어요.

## 실행 (로컬)

서버는 Node.js(20 이상)로 돌아가요. Node가 없으면 Docker로 실행하면 됩니다.

```bash
# Docker (권장)
cp .env.example .env        # OPENAI_API_KEY, GAME_PASSWORD 입력
docker compose up --build   # → http://localhost:8000

# 또는 Node가 있다면
npm install
OPENAI_API_KEY=sk-... GAME_PASSWORD=비밀번호 npm start
```

| 환경변수 | 설명 |
|---|---|
| `GOOGLE_CLIENT_ID` | 구글 로그인용 OAuth 클라이언트 ID (필수). 없으면 개발용 이름 로그인 (로컬 `npm start` 에서만) |
| `OPENAI_API_KEY` | NPC 대화용 키. 없으면 기본 대사로 동작 |
| `ADMIN_EMAILS` | 건의함을 볼 수 있는 관리자 구글 이메일 (쉼표로 여러 명). 게임 휴대폰 📮 건의함 또는 `/admin.html` |
| `GAME_PASSWORD` | 입장 비밀번호. 비워두면 누구나 입장 가능 |
| `OPENAI_MODEL` | 기본 `gpt-4o-mini` |
| `OPENAI_BASE_URL` | OpenAI 호환 API를 쓸 때 |
| `TIME_SPEED` | 현실 1초당 게임 분 (기본 1.5) |
| `DATA_DIR` | 세계 저장 위치 (기본 `./data`, Docker는 `/data`) |
| `STREET_CHAT_PER_MIN` | NPC끼리 거리 수다를 LLM으로 만드는 횟수 상한 (분당, 기본 6) |

## 구글 로그인 설정

1. [Google Cloud Console](https://console.cloud.google.com/apis/credentials) → **사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
2. 애플리케이션 유형: **웹 애플리케이션**
3. **승인된 JavaScript 원본**에 `https://jelly-city.fly.dev` 와 `http://localhost:8000` 추가 (리디렉션 URI는 필요 없음)
4. 처음이면 OAuth 동의 화면을 **외부 / 테스트** 로 만들고, 같이 할 동료 이메일을 테스트 사용자로 추가 (또는 앱 게시)
5. 발급된 클라이언트 ID(`....apps.googleusercontent.com`)를 `GOOGLE_CLIENT_ID` 로 설정. 클라이언트 보안 비밀번호는 쓰지 않아요

로그인하면 구글 계정마다 캐릭터를 4개까지 만들 수 있어요. 예전에 쓰던 캐릭터는 같은 브라우저로 처음 로그인할 때 자동으로 계정에 붙어요.

## 배포 (동료들과 함께 플레이)

세계 상태(시계, NPC, 차량)가 서버 메모리에 있으므로 **서버는 반드시 1대**로 돌려야 해요. WebSocket을 지원하는 곳이어야 하고, 정적 호스팅(GitHub Pages, Vercel 정적 사이트)으로는 안 됩니다.

### Fly.io + GitHub 자동 배포 (권장)
처음 한 번만 설정하면, 이후에는 `main` 브랜치에 push할 때마다 GitHub Actions가 검사하고 실서버에 배포해요 (`.github/workflows/deploy.yml`).

```bash
# 1) 처음 한 번: 앱 만들기 (fly.toml의 app 이름이 바뀌면 그대로 커밋)
brew install flyctl && fly auth signup
fly launch --copy-config --no-deploy
fly volumes create roach_data --size 1 --region nrt
fly secrets set GOOGLE_CLIENT_ID=....apps.googleusercontent.com OPENAI_API_KEY=sk-... GAME_PASSWORD=동료용비밀번호
fly deploy

# 2) GitHub에 배포 권한 주기
fly tokens create deploy -x 999999h   # 출력된 토큰을 복사
# GitHub 저장소 → Settings → Secrets and variables → Actions → New secret
#   이름: FLY_API_TOKEN / 값: 복사한 토큰

# 3) 이후로는 push만 하면 배포
git push origin main
```

- 배포하는 동안 서버는 세계를 저장하고 접속자에게 "업데이트 중"을 알린 뒤 재시작돼요. 접속 중인 브라우저는 몇 초 뒤 자동으로 새 코드를 받아 같은 캐릭터로 다시 접속해요.
- 세계 상태가 서버 메모리에 있으므로 머신은 꼭 1대로 유지하세요 (`fly scale count 1`).

### Render
1. 이 폴더를 GitHub 저장소로 올립니다.
2. Render → New → Blueprint → 저장소 선택 (`render.yaml` 사용)
3. `OPENAI_API_KEY`, `GAME_PASSWORD` 입력 후 배포

무료 플랜은 15분 동안 아무도 접속하지 않으면 잠들고, 디스크가 없어서 재시작하면 세계가 초기화돼요. 그래서 설정은 starter 플랜과 디스크 기준으로 되어 있어요.

### 비용과 보안
- 동료들의 모든 NPC 대화는 서버의 OpenAI 키로 과금돼요. gpt-4o-mini는 대화 1회에 약 1~2천 토큰이 들어요.
- 키는 서버에만 있고 브라우저로 전달되지 않아요. 입장 비밀번호를 꼭 설정하세요.

## 게임 내용

- **도시**: 6×6 블록에 48종의 건물이 있어요. 공원을 뺀 모든 건물에 들어갈 수 있고, 실내가 각기 다르게 꾸며져 있어요.
- **시민 140명**: 이름, 나이, 성별(남/여), 직업 76종, 성격 20종, 가족·역할·취미·고민·꿈이 있어요. 플레이어처럼 체력, 배고픔, 에너지, 재미, 사교, 청결 욕구가 있어서 배고프면 식당에, 피곤하면 집에, 다치면 병원에 가요. 모두 자기 집이 있어요.
- **전투**: 기본은 주먹이에요. 무기는 근접(검·창·용월도·광선검), 총(권총·산탄총·소총·저격총·미니건·블래스터·활), 투척(수류탄·열 폭탄), 로켓(RPG·이온 캐논)이 있고, 전차와 헬기도 살 수 있어요. 투구·방탄모·갑옷은 방어력을 올려줘요.
- **보석 인챈트**: 루비(공격력), 사파이어(공격속도), 에메랄드(흡혈), 토파즈(치명타), 자수정(독), 다이아몬드(방어 관통), 흑요석(사거리), 오팔(넉백)을 무기의 보석 칸에 박아요. 방어구에 박으면 방어력·재생·이동속도·매력이 올라가요.
- **수배와 진압**: NPC를 공격하면 수배 별이 오르고, 경찰 → 군대·전차·헬기 순으로 출동해 사격해요. NPC는 맞으면 도망가거나(성격에 따라) 덤벼요. 플레이어든 NPC든 죽으면 집에서 체력이 가득 찬 채로 부활해요.
- **탄약**: 총과 활은 탄약이 있어야 쏠 수 있어요. 권총탄·산탄·소총탄·저격탄·미니건 탄띠·로켓탄·에너지 셀·이온 코어·화살이 총마다 따로 있고, 총을 사면 첫 탄약 한 묶음을 줘요. 활(장궁·각궁·제갈연노)은 실제로 날아가는 화살을 쏴요.
- **무기 드랍**: 거리 곳곳에 무작위 무기가 떨어져 있어요(일반·고급·희귀·전설). 희귀도 색깔의 빛기둥이 멀리서도 보이고 미니맵에도 ◆로 표시돼요. 총은 그 총의 탄약, 활은 화살과 함께 떨어져요. 주우면 화면 가운데와 전체 채팅에 알림이 뜨고, **30분 동안만** 쓸 수 있어요. 시간이 끝나면 어느 상점에서 얼마에 살 수 있는지 알려줘요. 서버는 항상 14개쯤을 유지해요(`WORLD_DROPS`).
- **교통사고**: 차에 치이면 속도에 비례해 다쳐요(느리면 가볍게, 빠르면 즉사). 플레이어가 운전하다 사람을 치면 수배가 붙어요.
- **길찾기**: 지도에서 목적지를 찍으면 보도를 따라가는 경로가 미니맵과 땅 위 화살표로 표시되고, 1초마다 다시 계산돼요. R로 자동 이동해요. 미니맵은 카메라가 보는 방향이 위쪽이에요.
- **도시 경계**: 외곽 도로까지는 자유롭게 다닐 수 있고, 그 바깥 들판은 꽃 산울타리로 막혀 있어요.
- **자동차**: 모든 차를 빼앗아 탈 수 있어요. 유리창 너머로 운전자와 동승자가 보이고, 빼앗으면 뛰쳐나와 도망가요.
- **집**: 처음엔 호텔에서 지내다가 부동산에서 집을 사요.
- **치장과 클럽**: 모자, 안경, 옷, 액세서리를 입으면 매력이 올라가요. 매력 40 이상이면 양복에 선글라스를 낀 경호원이 클럽에 들여보내줘요.
- **무릉도장**: 제한 시간 안에 점프맵을 통과하면 2단 점프, 고급 점프맵은 3단 점프, 용암 징검다리는 대쉬를 배워요.
- **인벤토리**: 하단 10칸 핫바에서 무기, 음식, 인형을 골라 써요. 바닥에 버린 아이템은 1분 뒤에 사라지고, 다른 사람이 주울 수 있어요.
- **기분**: NPC는 0~100의 기분이 있어요. 배고프거나 피곤하거나 외로우면 떨어지고, 수다·좋아하는 장소·칭찬·선물로 올라가요. 맞거나, 폭력을 목격하거나, 욕을 들으면 크게 떨어지고, 성격에 따라 상처받는 정도와 회복 속도가 달라요. 기분은 얼굴 표정과 머리 위 이모지, 말투에 드러나요.
- **신고**: 특정 플레이어에게 원한이 쌓이면(욕설, 폭행, 난폭 운전) 그 NPC는 말을 걸어도 거절하고, 성격에 따라 직접 경찰서로 걸어가 신고해요. 신고가 접수되면 그 플레이어에게 수배가 붙어요. 접속하지 않은 사이에 들어온 신고는 다음 접속 때 적용돼요.
- **LLM 대화**: NPC는 자기 프로필, 지금 하는 일, 몸 상태(배고픔 등), 친밀도, 기억을 바탕으로 gpt-4o-mini로 대답해요.
- **멀티플레이**: 모두가 같은 도시, 같은 시간, 같은 NPC를 봐요. 서버가 진짜 주인이고, 밤에 모두 잠들면 아침이 와요.

## 구조

```
server/index.js        HTTP(정적 파일) + WebSocket 서버, 시뮬레이션 루프(20Hz), 스냅샷 전송(10Hz)
server/world.js        공유 세계: 시계, 시민·차량 시뮬레이션, 플레이어, NPC 대화(LLM), 잠 투표, 저장
server/combat.js       전투·수배·경찰/군대 AI·바닥 아이템
server/llm.js          OpenAI 호환 API 호출 (서버 전용)
public/index.html      UI 뼈대 (import map으로 three.js 로드)
public/js/
  main.js              렌더러, 낮밤, 입력, 상호작용, 욕구, 행동, 네트워크 처리
  net.js               WebSocket 클라이언트
  views.js             서버 스냅샷으로 시민과 다른 플레이어를 그리는 레이어
  world-setup.js       서버와 브라우저가 같은 시드로 같은 도시·시민을 만드는 공통 초기화
  citizens.js          시민 생성과 일과 AI (서버에서 실행)
  traffic.js           차량 AI (서버) / 차량 메쉬(탑승자·전차·헬기)와 내 차 운전 (브라우저)
  items.js             무기·방어구·치장·음식·보석 데이터베이스
  inventory.js         인벤토리·핫바·장비
  combat.js            조준·타격·투사체·폭발 이펙트 (브라우저)
  prompts.js           LLM 프롬프트와 기본 대사
  city.js, interior.js, roach.js, player.js, ui.js, data.js, config.js, utils.js
```

개발용 URL 파라미터: `?autostart&pw=비밀번호&name=이름` (시작 화면 건너뛰기)
